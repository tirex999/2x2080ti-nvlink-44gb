# Strata на 2×2080Ti: патч под две карты и два сокета

Патч к [Strata](https://github.com/Niko1221/Strata) v0.1.2 (коммит `6da1f66`) — движку под одну модель,
Qwen3.8-Flash-Next. Из коробки Strata собирается только для sm_80 и новее и работает на одной карте. Патч
переносит её на 2080Ti (sm_75) и даёт работать на двух картах и двух сокетах.

На нашем стенде (2×2080Ti 22 ГБ, 2×Xeon Ice Lake, квант ISTA GSQ-RCO IQ3_XXS) это **50–68 т/с** на задачах
«хомяки» и «аквариум». Strata без доработок на одной карте даёт 25–39 т/с. С `--numa` наш 4-битный квант (эксперты
IQ4_XS/IQ4_NL, плотная часть и таблица Q8_0) идёт **67–75 т/с** на коротких ответах; прямой замер на одном промпте —
39.7 → 71.7 т/с при том же выходе бит в бит. Таблицы, оценка сцен и сравнение с llama.cpp — на странице
[Flash-Next](https://tirex999.github.io/2x2080ti-nvlink-44gb/flash-next.html).

**Сейчас (03.10.2026) этот патч вырос в отдельный движок — [DACAN](https://github.com/tirex999/DACAN)** (форк
Strata 0.1.9). Замер на свободном узле: 77–80 т/с на коде и списках, 72 на ответе с размышлением low, 70 на контексте
98K, 60 на английской прозе и 47 на русской; промт с нуля — 786 т/с на 19K и 715 на 98K. Числа выше — замеры этого
патча 27.09.

## Что в патче

| что | ключ или переменная |
|---|---|
| Перенос на sm_75 | — |
| Пул процессора на Linux: один рабочий на физическое ядро | — |
| Работа на двух сокетах | `--numa`, `STRATA_NUMA_WORKERS=a,b` |
| Таблица n-грамм в памяти | `STRATA_PLE_LOCK=0`, `STRATA_PLE_RESIDENT=0`, `STRATA_GGUF_KEEP_CACHE=1` |
| Рабочие пула без работы засыпают | `STRATA_POOL_IDLE_MS` (0 — не засыпать) |
| Вторая карта | `--second-card 1`, `--second-card-usage`, `--second-card-reserve-mib` |
| Таблица маршрутизации своих прогонов | `STRATA_USAGE_DUMP=файл`, `tools/mk_profile_from_usage.py` |
| Свои ядра гипер-связей | `STRATA_GR_V1=1` — штатные |
| `--pcie-frac 0` для двух карт | `--pcie-frac 0` |
| Эксперты IQ4_XS на карте, таблица токенов и таблица n-грамм в Q8_0 | таблица Q8_0 — только `--ple-io mmap` |

## Сборка

```bash
git clone https://github.com/Niko1221/Strata && cd Strata && git checkout 6da1f66
git apply ../strata-2x2080ti.patch     # проверено: встаёт на чистую 0.1.2
# зависимости, пакет модели, MTP — по README Strata (setup.sh, tools/iq_pack.py, tools/mtp_fetch.py, tools/mtp_rt.py)
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DSTRATA_ENABLE_CUDA=ON -DSTRATA_NATIVE_EXPERTS=ON \
      -DCMAKE_CUDA_ARCHITECTURES=75 -DSTRATA_GGML_DIR=/путь/к/llama.cpp
cmake --build build -j
```

У нас: CUDA 13.0, gcc 15, драйвер 610, ggml из llama.cpp `3cf03257`.

## Запуск на двух картах и двух сокетах

Главная карта становится устройством 0, вторая — устройством 1 (у нас главная — карта 1 на сокете 1). С `--numa`
`numactl` не нужен, а `--membind` ему мешает:

```bash
CUDA_VISIBLE_DEVICES=1,0 ./build/strata --numa \
  --pack <пакет> --native <шард 1> --ple-gguf <шард 2> --ple-io mmap \
  --expert-profile data/profile_other_2609.bin --expert-cache auto --adapt-every 0 \
  --second-card 1 --second-card-usage data/usage_other_2609.bin --pcie-frac 0 \
  --prefill 2048 --spec 4 --spec-min-p 0.5 --mtp <mtp/rt> --max-context 131072 --kv int8 --tokens ...
```

В журнале должно быть `NUMA: ...` и `n-gram table: 50.7 of 50.7 GiB in memory ...; locked`.

Сервер с OpenAI-совместимым API — `run-fast.sh` в этой папке: он пишет конфиг для `serve/server.py` Strata с
теми же ключами (`NUMA=0` — прежний режим на одном сокете).

## Таблицы маршрутизации (`data/`)

`profile_other_2609.bin` и `usage_other_2609.bin` — таблицы для команды выше. Сняты на модели ISTA IQ3_XXS, по 1024
токена ответа на шести промптах: задачи «майнкрафт» и «хомяки-физика», два разговора, проба на 4.6 тыс. токенов и
короткий бенч. Хомяков и аквариума среди них нет.

Своя таблица: `STRATA_USAGE_DUMP=usage.bin ./build/strata ...` на своих запросах (таблица копится между
прогонами), затем `python3 tools/mk_profile_from_usage.py usage.bin profile.bin 9000`.

## Что важно знать

- **Память.** С `--numa` таблица n-грамм закреплена в ОЗУ: процесс держит экспертов (61 ГиБ у 4-битного кванта,
  40 ГиБ у ISTA) плюс таблицу (51 ГиБ в Q8_0, 27 ГиБ в IQ4_NL). Если рядом должны жить виртуальные машины, считайте
  это заранее; `STRATA_PLE_LOCK=0` оставляет таблицу в кэше ОС без закрепления.
- **Нагрев главной карты.** У нас она доходит до 84 °C — это целевая температура 2080Ti, на ней драйвер держит карту,
  сбрасывая частоту (`SW Thermal Slowdown`, 1545 МГц из 2100 при вентиляторе 51 %). Сильнее всего это бьёт по долгим
  ответам; нужен обдув.
- Не запускайте две копии Strata разом: рабочие пула во время генерации заняты на всех ядрах.
- `--pcie-frac`: с одной картой лучше 0.15 (заводское 0.55 рассчитано на PCIe 4.0), с двумя — 0.
- Если голова модели (`output.weight`) в Q8_0, добавьте `--vram-reserve-mib 1024`. Запас по умолчанию, 700 МиБ,
  рассчитан на голову Q5_K; без него движок пишет «mtp: the draft head does not fit». В `run-fast.sh` для этого
  есть переменная `EXTRA`.
- Не помогли: огромные страницы, окно черновика 6, запуск графа отдельным потоком — всё это оставлено выключенным.
- Один запрос за раз; кэш между запросами не переиспользуется, каждый ход перечитывает весь контекст.
- Автор Strata предупреждает, что эксперт, посчитанный на карте, даёт другие токены, чем на процессоре: у них
  разное квантование активаций (оба способа — из llama.cpp). На наших задачах качество сцен на одной и двух
  картах одинаковое. `--numa` результат не меняет: выход с ним и без него совпадает бит в бит.
