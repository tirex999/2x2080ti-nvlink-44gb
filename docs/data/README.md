# Сырые замеры

Здесь лежит то, из чего посчитаны выводы в [`../results.md`](../results.md).
Не пересказ, а исходные окна замера — чтобы каждый мог пересчитать сам и,
если надо, опровергнуть.

## `mtp-throughput-2026-08-31.tsv`

Один прогон vLLM `0.2.1-pre3` с Qwen3.8-27B AWQ-MTP на двух RTX 2080 Ti
(модифицированные, 22 ГБ каждая, NVLink NV2). Профиль: `MTP_K=4`,
`MAX_NUM_SEQS=1`, TP=2, KV не сжат, контекст 131072.

152 строки — по одной на каждое десятисекундное окно, которое сервер пишет
в журнал сам. 148 из них содержат статистику спекулятивного декодирования.

| колонка | что это |
|---|---|
| `utc` | время окна, **UTC** (контейнер живёт по UTC) |
| `gen_tps` | токенов в секунду генерации за окно |
| `prompt_tps` | токенов в секунду обработки промпта за окно |
| `running` | сколько последовательностей считалось одновременно |
| `kv_pct` | занятость KV-кэша |
| `prefix_hit_pct` | попаданий в кэш префикса |
| `acc_len` | среднее число токенов, снятых с одного прохода (1…5) |
| `acc_rate_pct` | доля принятых черновиков |
| `drafted_tps` | темп черновой головы |
| `accepted_tps` | темп принятых токенов |
| `pos1`…`pos4` | доля принятия по каждой позиции черновика |

**Важно про нули.** Окна с `gen_tps` около нуля — не сбой, а промежутки,
где генерация занимала долю окна: конец ответа, пауза между сообщениями.
Их надо отбрасывать при любом усреднении, иначе среднее уедет вниз.

## Что на этих данных проверяется

Главное тождество раздела 6:

```
gen_tps  ==  acc_len × (drafted_tps / MTP_K)
```

Скрипт [`../../scripts/verify_mtp_identity.py`](../../scripts/verify_mtp_identity.py)
считает его по каждому окну и печатает максимальную невязку, а не среднюю:
средняя спрятала бы отдельные промахи. На этих данных сходится в пределах
1 % в 122 окнах из 126 с генерацией; четыре несошедшихся — обрывки, где
темп черновика 1.13 вместо 94.

Второй скрипт, [`../../scripts/collect_mtp.py`](../../scripts/collect_mtp.py),
делает саму таблицу из журнала сервера — если хотите снять свою.

## Как снять то же самое у себя

Нужны включённые счётчики, иначе строк не будет вовсе:

```ini
Environment=DISABLE_LOG_STATS=0
```

Дальше:

```bash
python3 scripts/collect_mtp.py > my-run.tsv
python3 scripts/verify_mtp_identity.py my-run.tsv
```
