Хомяки: как разные модели справились

Одна и та же задача каждой модели: сделать одним файлом сцену на Three.js — клетка, несколько лоу-поли хомяков, один предмет, камера вращается. Три прогона на модель. Открывайте страницу и смотрите глазами; рядом лежит рассуждение модели — по нему видно, почему вышло так, а не иначе.

Условия одинаковы для всех: температура 0.6, top_p 0.95, top_k 20, глубина размышления medium, потолок 24000 токенов.
Прогон засчитан, если модель остановилась сама (finish=stop), в коде есть закрытый </html> и страница проходит не меньше 7 автопроверок из 8. Модель годна, если засчитано хотя бы 2 прогона из 3.
