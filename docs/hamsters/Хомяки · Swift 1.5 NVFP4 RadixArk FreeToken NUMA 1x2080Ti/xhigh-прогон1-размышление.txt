```js
function makeHamster(cfg, i){
  const g = new THREE.Group();
  const fur = new THREE.MeshStandardMaterial({color: cfg.fur, flatShading:true, roughness:0.9});
  const belly = new THREE.MeshStandardMaterial({color: cfg.belly, flatShading:true, roughness:0.95});
  const pink = new THREE.MeshStandardMaterial({color:0xf6a5b8, flatShading:true, roughness:0.7});
  const dark = new THREE.MeshStandardMaterial({color:0x2b2430, roughness:0.35, metalness:0.1});
  
  const body = new THREE.Mesh(new THREE.IcosahedronGeometry(0.5,1), fur);
  body.scale.set(1.05, 0.92, 1.22);
  body.position.y = 0.46;
  
  const bellyMesh = new THREE.Mesh(new THREE.IcosahedronGeometry(0.42,1), belly);
  bellyMesh.scale.set(0.95,0.8,1.05); bellyMesh.position.set(0,0.38,0.08);
  
  head group: position (0, 0.72, 0.5)
    head: IcosahedronGeometry(0.33,1) scale (1,0.95,1)
    snout: IcosahedronGeometry(0.16,0) scale(0.9,0.8,1.1) at (0,-0.03,0.3)
    nose: small sphere pink at (0,0.0,0.42)
    eyes: sphere(0.062, 6,5) at (±0.15, 0.08, 0.26)
    glints: sphere 0.02 white at eye + offset
    ears: group at (±0.2, 0.26, 0.02) rotate z ±0.5: cylinder(0.13,0.13,0.045, 8) rotated x=PI/2 → disc facing sideways; plus inner pink disc smaller.
    cheeks: sphere 0.14 at (±0.24,-0.02,0.16) scale (1,0.9,0.9) with fur color, animate scale for eating.
  
  legs: 4 groups at (±0.26, 0.16, ±0.28) each with cylinder(0.08,0.1,0.24,5) mesh offset y=-0.12, plus foot sphere.
  tail: sphere 0.07 at (0,0.42,-0.58)
  
  All meshes castShadow = true.
}
```

Now the AI state machine:

```js
const S = { IDLE:'idle', WALK:'walk', TURN:'turn', EAT:'eat', WHEEL:'wheel', NAP:'nap', TUNNEL:'tunnel', GROOM:'groom', SEEK:'seek' };
```

Each hamster:
```js
{ group, parts, pos: Vector3, heading, speed, state, timer, target, name, color, hunger, energy, mood, stats... }
```

Update:
```js
timer -= dt;
switch(state){
 case IDLE: if timer<=0 → choose next
 ...
}
```

chooseNext(h): weighted random based on hunger/energy:
- if hunger > 0.65 and seeds available → SEEK seed (or bowl)
- if energy < 0.25 → NAP (go to hut)
- if wheel free and rand<0.3 → WHEEL
- if rand<0.2 → TUNNEL
- if rand<0.3 → GROOM
- else WALK (random waypoint)

Movement: steer toward target with turn rate; clamp inside bounds; avoid obstacles (circle repulsion list).

Obstacles: wheel (circle r=1.5 at pos), bowl (r=0.6, walkable to eat—handle as target not obstacle), hut (r=1.0 solid, door target), tunnel (walkable through).

Simple approach: obstacle circles for wheel base and hut; hamsters steer around by adding a repulsion vector when within radius.

Seeds: array of {mesh, pos, eaten}. Hamster seeking: find nearest seed, set target; when within 0.45, eat: seed removed, hunger -= 0.5, head dip animation, log.

Bowl: has seeds count; hamster targets bowl rim position; each 0.4s reduces bowl seeds by 1 and spawns a "crumb" effect; hunger decreases.

Wheel: occupancy; when hamster arrives at wheel, sets wheel.occupant; wheel spins with hamster's running; RPM stat = angular velocity.

Tunnel: define tunnel endpoints A and B; hamster targets A, then moves along to B, then state WALK.

Nap: target hut interior; curl; energy increases; after timer, wake.
