Implementation approach: each hamster has `state`, `timer`, `target` (Vector3), `speed`.

update(dt):

- Movement: dir = target - pos (y locked); if len<0.25 → arrived handler.
- yaw lerp toward atan2(dir.x, dir.z).
- walkPhase += dt * speed * 9; legs rotate sin(phase)*0.7; body bob y = sin(phase*2)*0.03; slight roll.
- if state 'pause': idle animation: ear wiggle, sniff (nose scale), occasional head tilt.
- 'groom': quick paw rub — arms rotate forward, spin slightly.
- 'nap': curl: lerp scale.y to 0.75, legs tuck, eyes closed (eye scale y 0.12), Zzz particles spawn every ~1.4s.
- 'wheel': move to wheel mount point then lock; wheel speed up; legs scramble fast; leave after timer.
