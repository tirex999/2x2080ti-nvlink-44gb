## 🐠 3D Аквариум с Реалистичными Рыбками

**Stack:** Vite + React 18 + TypeScript + Three.js (r128) + OrbitControls

### Key features implemented
- **15 разноцветных рыбок** — процедурная модель (тело, глаза с зрачками, анимируемый хвост, плавники), 8 цветовых схем, случайный размер 0.6–1.2
- **ИИ поведения** — избегание столкновений, отражение от стен, случайное блуждание, преследование корма, рост на 5% после поедания
- **Окружение** — стеклянный контейнер (MeshPhysicalMaterial с transmission), песчаное дно с процедурными неровностями, 8 деформированных камней, 12 водорослей (TubeGeometry + CatmullRomCurve3 с покачиванием)
- **Система пузырей** — 30 на старте, движение вверх с покачиванием, сброс на поверхности, кнопка «+10»
- **Кормление** — клик по воде создаёт корм с гравитацией, рыбки в радиусе 15 плывут к нему, при съедании удаляется + рыбка растёт
- **Освещение** — Ambient + Directional (тени 2048², PCFSoft) + 2 PointLight (подводный эффект), туман FogExp2, градиентный фон
- **Камера** — OrbitControls с damping, зум 10–60, ограничение polar angle
- **UI** — glassmorphism-панели: слева инструкции + кнопки («Добавить рыбку», «Больше пузырей», «Свет»), справа статистика (число рыбок, FPS)

### Как запустить
```bash
npm run dev      # dev-сервер
npm run build      # продакшен-сборка в dist/
npm run preview    # локальный предпросмотр сборки
```

Откройте в браузере, вращайте сцену мышью, кликайте по воде чтобы бросить корм — рыбки поплывут к нему и подрастут.
