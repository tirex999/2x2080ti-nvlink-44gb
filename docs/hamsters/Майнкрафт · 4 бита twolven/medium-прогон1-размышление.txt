Wait, in Three.js r128, vertexColors is a boolean property. Let me check: yes, in r128, `MeshLambertMaterial({ vertexColors: true })` enables per-vertex coloring.

The vertex colors are stored as Float32Array in the BufferGeometry's 'color' attribute. Each vertex has 3 components (R, G, B) in [0, 1] range.

For a block with base color (r, g, b) and face brightness m:
- Vertex color = (r * m, g * m, b * m)

Since I'm using MeshLambertMaterial, the final pixel color = vertexColor * ambientLight + vertexColor * diffuseLight * dot(normal, lightDir). With the ambient light at 0.65 and directional at 0.8, the faces will have different brightness based on their orientation relative to the light source.

But wait, I'm already encoding face brightness in the vertex colors (top=1.0, side=0.8, bottom=0.55). The directional light will add MORE variation based on face orientation. This might make the top faces too bright and the bottom faces too dark.

Hmm, let me think about this. The directional light is at some angle (say, from the upper-left). The dot product of the face normal with the light direction determines the diffuse contribution.

For a face pointing straight up (normal = (0,1,0)):
- If light comes from above at 45°: dot((0,1,0), lightDir) ≈ 0.7
- Diffuse contribution: 0.8 * 0.7 = 0.56
- Total: ambient (0.65) + diffuse (0.56) = 1.21 (clamped to 1.0)

For a face pointing horizontally (normal = (1,0,0)):
- dot((1,0,0), lightDir) ≈ 0.5 (depending on light angle)
- Diffuse: 0.8 * 0.5 = 0.4
- Total: 0.65 + 0.4 = 1.05 (slightly clamped)

For a face pointing down (normal = (0,-1,0)):
- dot((0,-1,0), lightDir) ≈ -0.7 (negative → no diffuse)
- Total: 0.65 (ambient only)

So the directional light does add realistic shading. Combined with the vertex color brightness (which acts as a base tint), the overall effect should look good.

Actually, I realize the vertex color brightness and the directional light are somewhat redundant. Both are trying to make different faces different shades. But they work together: the vertex color sets the base brightness, and the directional light adds a slight variation on top. The net effect is a nice-looking pseudo-lit surface.
