# Проверки качества и контекста

Этими скриптами сняты галерея (`docs/hamsters/`) и иголка из раздела Flash-Next. Нужен сервер с OpenAI-совместимым
API (llama-server, vLLM, DACAN). Ответы запрашиваются без потолка длины, как у боевого клиента: потолок ставится
от контекста, а не числом.

| файл | что делает |
|---|---|
| `benchmarks.py` | четыре задачи (хомяки, хомяки-физика, аквариум, майнкрафт), для каждой — промпт из `prompts/`, порог годности и проверки-регэкспы; каждая проверка выведена из явного требования промпта |
| `bench_ext.py` | один прогон задачи: пишет в галерею код (`.html`), размышление, ответ целиком и `.json` с вердиктом |
| `quality_cmp.py` | сводка галереи по задачам и уровням размышления: проверок пройдено / всего, годен ли |
| `recheck_anim.py` | перепроверка старых прогонов после правки проверки «цикл анимации» (`setAnimationLoop` засчитан) |
| `needle.py` | иголка: кодовое слово на 40 % глубины длинного промпта (8K, 32K, 128K, 240K токенов по счёту знаков), префилл из `/metrics` сервера |

Запуск одного прогона (адрес сервера, контекст, ключ задачи, прогонов, подпись, полное имя, квант, уровень размышления):

```bash
BENCH_BASE=http://127.0.0.1:8000 BENCH_CTX=262144 BENCH_OUT=gallery \
  python3 bench_ext.py хомяки-физика 1 "Flash-Next NVFP4 Дацан 2x2080Ti 256K" "полное имя модели" "4 бита" xhigh
```

Уровни размышления: `нет` (отключает размышление ключом `enable_thinking`), `low`, `medium`, `xhigh`. Выборка в
`bench_ext.py`: температура 0.6, top_p 0.95, top_k 20, штраф за повторы 1.05.

Сводка и иголка:

```bash
GALLERY=gallery python3 quality_cmp.py Flash-Next
NEEDLE_CORPUS=/путь/к/большому/каталогу/py NEEDLE_OUT=needle.json python3 needle.py http://127.0.0.1:8000
```

`needle.py` читает скорость префилла из `/metrics` сервера DACAN/Strata (`requests`, новые первыми). На другом сервере
поля префилла будут пустыми, но поле «нашла» заполняется всё равно.

Сторож ядер для соседней ВМ: `scripts/dacan-cpu-guard.sh`, `systemd/dacan-cpu-guard.service`, калибровка —
`scripts/quality/calib_guard2.sh` (номер ВМ и адрес движка в них наши, поправьте под себя).
