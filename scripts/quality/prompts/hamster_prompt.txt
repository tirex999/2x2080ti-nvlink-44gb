Prompt: Low-Poly 3D Hamster Playground
Create a single-file browser project called "Low-Poly Hamster Playground".
The page should show a small 3D hamster cage scene with several cute low-poly hamsters. The user should be able to rotate the camera and watch the hamsters move around.
Requirements:
Use Three.js.
Everything must be in one index.html file.
The scene should include a cage, a floor/tray, several low-poly hamsters, and one interactive object such as a wheel, tunnel, food bowl, or toy.
Hamsters should have simple autonomous behavior: walking, pausing, turning, or interacting with one object.
The visual style should be cute, low-poly, colorful, and funny.
The project should run immediately in a modern browser.
Do not overcomplicate the scene. Focus on making it stable, readable, visually clear, and fun
